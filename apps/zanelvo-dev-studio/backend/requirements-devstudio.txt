# OPTIONAL runtime dependencies. All are lazily imported (see app/devstudio/providers/*_provider.py
# and app/devstudio/services/browser_service.py) so the app boots and its core tests pass without
# any of them installed. Install this file in the runtime that actually runs agents / browser QA:
#
#   pip install -r requirements-devstudio.txt
#   python -m playwright install --with-deps chromium   # first time only, for browser QA

# Emergent Universal Key support (emergentintegrations) is intentionally NOT listed here — every
# published version of it hard-pins openai==1.99.9, which conflicts with the openai==1.109.1 pin
# below for the native OpenAI provider; pip's resolver refuses to install both in one environment.
# Install it separately via requirements-emergent.txt (which pins its own compatible openai) if you
# want Emergent — see that file's header for the tradeoff. Lazily imported either way, so nothing
# here breaks if it's absent.
anthropic[vertex]==0.69.0
openai==1.109.1
# Also covers GeminiEnterpriseProvider (Vertex AI / Gemini Enterprise Agent Platform) — same SDK,
# different client auth; google-auth (for service-account credentials) ships as its dependency.
google-genai==1.75.0
# google-genai's own async transport (_api_client.py) references aiohttp.ClientConnectorDNSError
# directly in an `except (...)` tuple — that class was only added in aiohttp 3.10.0. An older,
# already-installed aiohttp (e.g. one pulled in earlier by an unrelated package) makes ANY network
# error on a Gemini/Gemini Enterprise call surface as "module 'aiohttp' has no attribute
# 'ClientConnectorDNSError'" instead of the real error — reproduced directly against the pinned
# google-genai==1.75.0 source (see the commit that added this line). Floor-pinned, not exact, since
# this is guarding a minimum SDK feature rather than matching an exact tested release.
aiohttp>=3.10.0
playwright==1.55.0
# boto3's own release cadence is far faster than the pinned packages above and its exact current
# version wasn't checked against a live index this session (unlike anthropic/openai/google-genai,
# see the commit that added them) — floor-pinned rather than exact-pinned for that reason.
boto3>=1.34.0
# MCP (Model Context Protocol) client — lets agents call tools exposed by connected MCP servers
# (see app/devstudio/services/mcp_service.py). mcp>=1.10 requires a newer sse-starlette which in
# turn requires starlette>=0.49.1, conflicting with fastapi==0.116.1's starlette<0.48.0 pin — this
# was reproduced with an actual `pip install` (not assumed), so both are pinned explicitly to
# versions verified to coexist: mcp==1.9.4 (Requires-Dist: starlette>=0.27, no ceiling) with
# sse-starlette explicitly pinned below its own starlette>=0.49 floor (introduced in its 3.x line).
mcp==1.9.4
sse-starlette==2.1.3
